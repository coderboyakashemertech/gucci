# COUTURE Home

Mobile home redesign in a Gucci-app editorial structure: five full-bleed thumbnails, gothic titles, black-and-white composition.

Three banners fit on one screen. Scroll for the remaining two.

1. **BEAUTY** — video-ready autoplay slot  
2. **FASHION**  
3. **LIFESTYLE GOODS**  
4. **E-SHOP**  
5. **RESERVATION**

Titles use Julius Sans One. Images stay full-bleed with no extra graphics besides the title.

## Run

```bash
npm install
npm run dev
```
